Captura de Leads — Cloudflare KV

Arquitetura proposta: substituir Supabase por Cloudflare KV para ingestão de leads da landing page. Zero banco relacional, baixa latência, escalável.

📐 Implementação KV

  • Namespace: OPERUS_LEADS
  • Key: lead:{timestamp}:{email_hash}
  • Value: { name, email, crm, uf, specialty, plano, source, created_at }
  • TTL: 90 dias (configurável)
  • Rate limit: 1 lead / email / 24h (dedup via KV get)

wrangler.toml

[[kv_namespaces]]
binding = "LEADS_KV"
id = "<namespace_id>"
preview_id = "<preview_id>"

📝 Formulário de Captura

Campos: Nome, Email, CRM, UF, Especialidade, Plano de Interesse.

Validação client-side + server-side via Cloudflare Worker route /api/leads.

Fluxo

  1. Usuário preenche formulário na landing
  2. POST /api/leads → KV put com dedup
  3. Resposta 201 + redirect para /cadastro?plano=...
  4. Webhook opcional para CRM/Pipedrive

Vantagens

  • Sem custo de banco relacional
  • Latency < 5ms leitura
  • Escala automática Cloudflare
  • LGPD: sem Dados sensíveis (hash email)
