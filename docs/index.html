Monorepo Operus & Arquitetura Cloudflare KV

Next.js 15 (App Router) + Expo SDK 52 + Cloudflare Workers KV Storage Engine

Cloudflare KV Engine
apps/web (Next.js 15)

App Router, SSR, Bento Grid, emissor de propostas e portal público de TCLE (/aceite-termo/:token).

apps/mobile (Expo SDK 52)

React Native, autenticação biométrica e câmera para registro da cicatrização pós-operatória.

Cloudflare KV Storage

Armazenamento de ultra-baixa latência na borda global com particionamento multi-tenant por prefixos (tenant:*, surgery:*, tcle:*).

Estrutura de Chaves Cloudflare KV Multi-Tenant

tenant:{tenantId}:meta

Dados da clínica, plano ativo, limites e configurações.

tenant:{tenantId}:surgery:{id}

Registro cirúrgico, códigos TUSS, hospital e equipe.

tenant:{tenantId}:patient:{id}

Prontuário cirúrgico, contatos e histórico clínico.

tcle:token:{publicToken}

Acesso público ao termo de consentimento e hash assinado.
